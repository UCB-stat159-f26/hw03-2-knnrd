# HW3: Tennis Career Package

This repository contains a Python package for retrieving a player's career match data from Tennis Abstract and plotting differences between the player's age and the opponent's age.

## Public Functions

The package has two main functions:

- `get_career_matches()` downloads and processes career match data
- `plot_age_difference()` creates the career age-difference scatter plot
